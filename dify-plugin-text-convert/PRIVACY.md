# Privacy Policy

This plugin converts documents locally inside the Dify plugin runtime.

- It does **not** send uploaded files or converted content to external third-party services.
- It does **not** collect, store, or share personally identifiable information for analytics or advertising.
- File bytes are processed in memory (or temporary plugin runtime storage managed by Dify) only to produce Markdown output for the current workflow or agent invocation.
- Retention of conversation history, uploaded files, or workflow logs is controlled by your Dify deployment configuration, not by this plugin.
